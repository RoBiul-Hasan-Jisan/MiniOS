# MiniOS Python Simulation

A complete operating system simulation written in Python that demonstrates core OS concepts including process scheduling, memory management, file systems, and system calls.

## Features

- **Process Management**: Round-robin scheduling with process states
- **Memory Management**: Virtual memory allocation and tracking
- **File System**: Virtual file system with directories and files
- **System Calls**: Simulated system call interface
- **Shell**: Interactive command-line interface
- **Drivers**: Simulated hardware drivers (keyboard, VGA, serial)
- **Applications**: Calculator, performance tests, and utilities
